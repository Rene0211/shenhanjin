# 夜行路线动效设计

## 目标

为交互设计求职作品集增加统一、克制的动效语言。动效需要强化“雨夜电话亭”的记忆点，并让招聘方在短时间内读清个人经历、案例和联系方式。

## 体验原则

- 内容优先：动画不遮挡文字，不锁定常规滚动，也不改变页面信息层级。
- 一条路线：以青蓝色细光线作为章节之间的视觉连接，不新增独立的主题或插画。
- 有节奏但不喧闹：首屏承担最强记忆点；经历、项目和联系方式依次减弱为阅读提示与反馈。
- 无障碍与性能：尊重 `prefers-reduced-motion`，在触屏设备移除依赖鼠标位置的效果；只动画 `transform`、`opacity`、`clip-path` 和 CSS 变量。

## 动效组成

### 1. 章节路线

在首页内容区域增加一条低对比度的纵向路线。它由小节点和短光段组成，位置对应个人介绍、经历、项目、联系方式。

- 滚动进入每个章节时，当前节点点亮，前一段路线填充。
- 路线使用青蓝色微光，与电话亭场景已有的色彩一致。
- 桌面端固定在内容边缘；小于 900px 的屏幕隐藏路线，避免挤压正文。
- 路线只在首页使用，不进入项目详情页。

### 2. 个人介绍与经历

- 个人介绍的身份卡保留现有入场及磁吸交互。
- 经历时间线节点由暗到亮依次激活，卡片维持现有上移揭示。
- 当前进入视口的节点使用一次 400ms 的柔和扫光，随后维持静态高亮。

### 3. 项目案例

- 每张项目卡片进入时，从左至右完成一次窄幅扫光，并以现有遮罩揭示图像。
- 卡片悬停保留已有图片视差，增加边框微光与项目编号的短暂显现。
- 不使用横向滚动、固定滚动或自动轮播，保证案例可连续浏览。

### 4. 联系方式收尾

- 电话亭保持现有可点击开门与信箱取信交互。
- 联系区首次进入时，背景灯光从低亮度过渡到正常亮度。
- 鼠标靠近电话亭时，局部灯光的呼吸幅度略微增加；离开后回到静态。
- 电话亭门打开时，从门缝向外扩散一次短促的冷色光，不改变信箱图层。

## 实现边界

- 将首页时间轴与章节入场逻辑继续放在现有 `HomePage` 的 GSAP 生命周期中，使用当前的 `useGSAP`、`motionDuration`、`motionEase` 和 reduced-motion 分支。
- 新增的路线组件只渲染静态 DOM，进度由 ScrollTrigger 更新 CSS 自定义属性或类名。
- 项目卡片的扫光和编号只通过 CSS 伪元素完成；不增加新的图片资源。
- 联系区的灯光通过已有 `.contact-phone-light` 及新局部伪元素完成；不能重用整幅开门图片覆盖场景。
- 现有项目详情页动效不在此范围内。

## 验收标准

1. 桌面首页从首屏滚动到联系方式时，路线按章节顺序连续点亮。
2. 经历节点、项目卡片和联系区各有一次可辨识的进入反馈，但文字始终可读且可选择。
3. 电话亭开门不会影响信箱的颜色或图层。
4. 触屏设备没有路线和鼠标靠近特效，现有点击交互仍可用。
5. 开启减少动态效果后，内容立即可见，且不会保留半透明、裁切或固定状态。
